# Ejercicio 02 — Flexbox Layouts

Semana 01 — Fundamentos RN | Tiempo estimado: 1.5h

En este ejercicio se replican layouts clásicos de aplicaciones móviles usando Flexbox en React Native.

## 🎯 Objetivos

- Practicar `flexDirection`.
- Practicar `justifyContent`.
- Practicar `alignItems`.
- Usar `flex` para distribuir espacio disponible.
- Crear layouts comunes de apps móviles.

## 📋 Requisitos previos

- Haber leído `03-flexbox-layout.md`.
- Conocer los Core Components básicos.
- Tener un proyecto Expo funcionando.

## 🚀 Cómo empezar

```bash
cd ejercicio-02-flexbox-layouts/starter
pnpm install
pnpm start
